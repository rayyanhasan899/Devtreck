# Git workflow

The user requests that GitHub stay current alongside implementation work.

- Commit verified, coherent milestones and push the active branch promptly.
- Preserve unrelated edits; include them only when the user authorizes it.
- Keep the existing private repository and origin. Never force-push or rewrite published history.
- Update main when explicitly requested; otherwise use a feature branch and review workflow.
- Report the pushed branch and commit, and distinguish GitHub updates from live deployments.
