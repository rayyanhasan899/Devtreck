# Visual foundation

Slate text and surfaces, restrained teal accent, readable system typography and generous spacing. Light/dark palettes follow the OS; data-theme overrides are ready for settings in phase 6. No nonfunctional theme selector appears now.

CSS tokens in apps/web/src/app/globals.css own background/surface/ink/muted/border/accent/radius/fluid spacing. Hero typography scales 42–68px, body 14–18px. Cards use 16–24px radii and explicit borders. Below 800px the hero and feature cards stack.

Primitives: branded home link, semantic section headings/cards, skip link and anchored primary action. Visible keyboard focus, reduced-motion scrolling and semantic landmarks are included. Planned capabilities are labeled and no fake task records or unavailable signup links appear. Later app navigation/forms/dialogs reuse this foundation.
